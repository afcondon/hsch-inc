# 2026-04-04 / 2026-04-05: Ribbon layout generalization + cyclic Sankey + demo restructuring

## Accomplished

### hylograph-layout 0.3.0 published
Major feature release building the foundation for generalized "ribbon layouts" beyond Sankey diagrams.

**NodeValueStrategy parameterization**
- Added `NodeValueStrategy` newtype wrapping `FlowContext -> Number` — the node sizing function is now a parameter, not hardcoded
- `FlowContext = { incoming :: Array Number, outgoing :: Array Number }` gives the strategy full control over the fold
- Smart constructors: `sankeyNodeValue` (conservation of flow), `constantNodeValue` (topology-only), `bottleneckNodeValue` (capacity constraints), `maxNodeValue` (latency/bottleneck)
- Added to `SankeyConfig` with `sankeyNodeValue` as backward-compatible default
- Zero behavioral change for existing code — all golden tests pass unchanged

**Cycle detection and topology classification**
- Changed graph storage from `DAG` to `WeightedDigraph` to accept cyclic input
- DFS-based back-edge detection: single O(V+E) pass classifies all back-edges
- `CycleTopology` ADT: `Acyclic | EndCyclic | InteriorCyclic | MixedCyclic`
- `CycleAnalysis` in `SankeyLayoutResult` with classified back-edges (end vs interior)
- `RibbonLayout` ADT with `classifyLayout` — type-safe rendering dispatch, each constructor carries only the data its renderer needs
- Back-edges excluded from layout (BFS, relaxation) but included in node value sums for accurate sizing
- 4 new cycle tests added (end, interior, mixed, acyclic topology check)

**End-cyclic ghost rendering**
- For `EndCyclic` topology: faded predecessor | full central | faded successor
- CSS `mask-image` gradient for progressive fade (transparent at outer edge, ~90% at contact point)
- Back-edge ribbons at both junctions (predecessor→central AND central→successor)
- Gap between copies (6% of layout width) for visual break
- Warm-toned cycle ribbons visually distinct from forward flows

### hylograph-graph bug found and fixed
- Discovered that `findCycle` in Data.Graph.Algorithms returns phantom cycles for certain graph structures (nodes with shared sinks + cycles)
- The bug: DFS `path` array maintenance during backtracking loses track of which node is being exited when multiple recursive branches exist
- Workaround: wrote our own DFS back-edge detection (`findBackEdgePairs`) which correctly classifies all back-edges in a single pass
- Separate Claude session fixed `findCycle` and added tests to hylograph-graph
- Our algorithm promoted to hylograph-graph 0.3.0 as `findBackEdges`

## Explored But Not Pursued

**Interior cycle arcs below the diagram** — implemented bezier arcs curving below the Sankey for interior back-edges. Visually unconvincing — the fundamental problem is that interior cycles need a different LAYOUT algorithm (circular/radial within the linear flow), not just an SVG overlay. Removed the arc code.

**Supply chain small multiples** — implemented 3-panel comparison showing same topology with different record fields (weight, value, shipments). Technically worked but felt contrived — "a solution in search of a problem." Removed in favor of a note inviting real-world data contributions.

**Lead time / max fold** — the `maxNodeValue` strategy creates nodes smaller than the sum of their link widths, causing ribbons to overflow node bounds. The layout algorithm assumes node height accommodates stacked links. Non-sum folds need layout-level changes, not just strategy changes.

## Decisions Made

- **"Ribbon layout"** as the name for the generalized flow diagram engine (Sankey is one parameterized variant)
- **Four-way cycle taxonomy**: Acyclic / EndCyclic / InteriorCyclic / MixedCyclic — driven by rendering strategy, not graph theory
- **Interior cycles need a different layout algorithm**, not just different rendering — parked for future
- **End cycles are a presentation problem** solved by ghost copies of the same layout
- **Type-safe topology dispatch**: `RibbonLayout` ADT with `classifyLayout` — can't accidentally render with the wrong algorithm
- **"Relational"** as the page name for Chord, Edge Bundle, Adjacency (not "Flow" — they're not flow diagrams)
- **Manuscript palette** for colored Sankey (vermillion, ultramarine, gold-leaf, forest-green, tyrian-purple, ochre, malachite, ink-sepia)
