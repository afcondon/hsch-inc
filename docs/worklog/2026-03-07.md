# 2026-03-07

## Session Focus

Graph decomposition algorithms for hylograph-graph, and exploring chimera visualizations — multiple rendering styles for structurally decomposed graphs.

## Accomplished

- **Decomposition algorithms** (`src/Data/Graph/Decomposition.purs`): biconnected components, articulation points, bridges, bipartiteness detection, block-cut tree, decomposition metrics. All O(V+E). Published alongside existing graph algorithms in hylograph-graph.

- **62 tests** across 10 canonical test graphs (tree, cycles, barbell, star, K5, K3,3, diamond, path, bowtie). Tests verify articulation points by name, bipartite partitions by size, metrics including treelikeness.

- **Standalone demo** (`demo-decomposition/`): separate spago package with its own build. Three hand-crafted showcase graphs (Chimera, Archipelago, Caterpillar) with deliberately scattered node names so alphabetical vs block ordering produces maximum visual contrast.

- **Annotated graph view**: HATS-rendered graph with nodes colored by biconnected component, articulation points as diamonds, bridges as dashed lines.

- **Before/after adjacency matrices**: raw (alphabetical) vs block-ordered side by side. The block-ordered matrix reveals clean diagonal structure; the raw one looks scattered. The contrast is the demo's most immediately compelling visual.

- **4 chimera rendering styles**:
  - *Extracted*: blocks in a row, each in its classified form (matrix, bipartite Sankey, arc diagram, node-link)
  - *Chord*: dense blocks as chord diagrams, cycles as rings
  - *Spine*: block-cut tree laid out horizontally as skeleton, blocks rendered at tree positions, cut vertices as diamond junctions
  - *Orbital*: blocks as bodies in space along a gentle arc, shape encodes structure

- **Per-block renderers**: chord diagram (nodes on circle with bezier chords), ring (cycle-ordered nodes on circle), bipartite two-column with Sankey bands, arc diagram, circular node-link.

- **Les Miserables** as fourth showcase: 77 nodes, 254 edges loaded from JSON. Fruchterman-Reingold force simulation in JS FFI with group-based clustering. Shows decomposition on a real co-occurrence network — very different character from the hand-crafted graphs.

- **Shape classifier**: density > 0.5 = dense, bipartite with n > 3 = bipartite, edges == nodes = cycle, else sparse. Bridges are their own category.

## Decisions Made

- **Standalone demo package** rather than extending existing Honeycomb demo: avoids spago solver conflicts between registry and local hylograph-graph versions.
- **Scattered node names**: nodes named so alphabetical order interleaves blocks, making the before/after matrix contrast dramatic. K5 nodes get letters like c,e,h,l,q rather than a,b,c,d,e.
- **JS FFI for force layout**: simpler than adding d3-force as a dependency. Hand-rolled Fruchterman-Reingold with group gravity produces readable layouts for Les Mis.
- **Multiple chimera styles** rather than one "best" chimera: the same decomposition can be visualized many ways. Style selector lets you compare.
