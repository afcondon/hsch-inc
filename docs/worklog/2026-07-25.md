## Decisions Made

- Cluedo encoding uses 21 enum-valued constants, not an uninterpreted
  `holder :: Card -> Place` function — models of constants parse
  trivially (`get-model` define-funs with args would need ite-chain
  decoding), and nothing needed quantifiers.
- Hand sizes assert under the deal event's name (they are
  observations); one-envelope-card-per-category stays an unnamed
  domain axiom (it is a game rule).
- `entailed` mirrors the counting oracle's stance on contradiction:
  inconsistent observations entail *nothing* (session caches one
  up-front consistency check).
- Demo's gap-over-time exploits monotonicity: entailment only grows
  with observations, so once-entailed claims are cached across
  prefixes and never re-queried.
