# 2026-07-24

A long Brunel + Quartermaster session: the webapp got real routing and its first
taste of the integrated-config expressiveness, Quartermaster grew an `exec` verb
(and its Go column got repaired), and the fleet-view ambition was reframed from
homelab to enterprise scale.

## Accomplished

- **Brunel landing page — the encyclopedia cutaway** (artifact). A whimsical but
  load-bearing frontispiece: the deployment as a geological cross-section
  (crust = the webapp, mantle = the tools, outer core = the substrates, inner
  core = OS/Nix), the cutaway conceit matching Brunel's own thesis — making the
  OS-opaque legible. Status badges (aboard / framed / planned) + bespoke hazard
  chips; theme-aware SVG, accretion-from-the-core animation.

- **Brunel hash routing** (minard `1133580`). New `MinardNix.Route`
  (routing-duplex + `Routing.Hash`, the house pattern) + a thin URL-sync layer
  over the existing `Tab` machinery — every view is now a bookmarkable hash
  (`#/`, `#/projects`, `#/fleet`, …), back-button included, the seven render
  paths untouched.

- **The coherence widen — the `/analyze` boundary adopts the shared codec**
  (minard `edbe404`). Brunel's boundary was re-declaring a *thinner*
  ServiceInstance (5 fields) than Bosun serialises, dropping
  substrate/selectors/exposure/readiness before any view could see them.
  Replaced the hand-rolled `InstanceJ`/`instanceCodec` with `Bosun.Protocol`'s
  `ServiceInstanceView` + `analyzeResultCodec` (contract-as-shared-module — the
  module is explicitly "the wire contract for the Chair and now Brunel"). Now
  Brunel *cannot* parse a poorer model than Bosun's: coherence as a type
  identity, not a discipline. substrate/source/selectors/exposure/readiness flow
  `DService → TopoNode → topology.json` end to end.

- **Substrate lens** (minard `1133580`). A `Status | Substrate` colour toggle on
  the Fleet graph, orthogonal to the layout switch. Substrate mode colours
  service nodes by executor mechanism (docker/launchd/systemd/k8s/BEAM/native);
  the legend **auto-enumerates whatever substrates are present**; selection ring
  and blast-radius survive both lenses. The estate topology becomes the unified
  substrate map.

- **`quartermaster exec`** (qm `220d9b1`). `quartermaster exec [--flake REF]
  [--dry-run] -- <cmd>` sources the Nix daemon profile (putting the par
  toolchain on PATH) and auto-detects the repo's `.envrc` flake, so a
  non-interactive / agent shell can build any ecosystem repo with **no manual
  `nix develop` reach-around**. Pure `execScript` in core (applyScript
  discipline), streaming edge, exit-code propagation, Node + Gnomon Go columns.

- **Repaired the Gnomon Go column + every-verb conformance** (qm `2756573`).
  Building exec's Go twin surfaced that the Go binary **hadn't built since the
  `apply` verb landed** — `apply`/`publish` shipped Node-only, their Go FFI
  twins never written. Filled them, then widened `qm-conformance.sh` from
  verify+build to **every** verb (verify, build, publish, apply, exec, usage),
  added `make conformance`, and *verified* that removing a Go twin now fails the
  harness instead of passing silently.

## Decisions Made

- **Dogfooding rule (standing):** when a gap in our own toolkit surfaces
  mid-task, back off to fix the infra or at least write a spec — never silently
  work around it. First two instances handled this way: the agent-shell
  toolchain-PATH gap (→ `exec`) and the conformance coverage hole (→ every-verb
  harness).
- **The coherence bet, applied to the webapp:** widen the boundary and carry
  *all* the config through, via the shared type — not a widened re-declaration.
  Drift becomes a type error. AC's framing: coherence is why the whole system
  exists.
- **Brunel = enterprise fleet cartography, not a homelab tool.** Survey must
  scale to thousands of servers / whole data-centres. Encoding: ~5-colour
  provisioning buckets (top-3 configs + "outside top-3" + "non-standard");
  identical nodes collapse into count-sized **stacks** whose glyph self-explains
  its collapse criterion; a **user-pickable pivot** as the group-by axis (the
  facets that filter also aggregate — tags/geo/groups = the `selectors` already
  in the pipe); build/deploy = a **capability lens** (red/green/grey — where a
  service *can* build-or-deploy); provision/build/monitor are **lenses over one
  canvas**, not separate pages.
- **Synthetic fleet generator FIRST** — you can't design or test a scale UI
  against a 20-node homelab. Spec written this session.
- Commits go to `main`, unpushed (AC times pushes).
