# 2026-06-12 — signal-box: the polyglot demo gets its shape

## Accomplished

- **Resolved the "show-not-tell unrepresentability" conundrum** from
  last night's brainstorm. The key inversion: a QuickCheck generator
  derived from a type is a constructive proof of what the type can
  say — so the demo *measures the gap* between the representable set
  and the legal set (one oracle, written once) and shows refinement
  driving the gap to zero. Soundness (unsafe → 0) plus completeness
  (legal coverage held constant) — the squeeze comes from above only.
- **Built signal-box M1** (`~/work/afc-work/signal-box`, new top-level
  repo, Marginalia #226, related-linked to Polyglot #134). Railway
  interlocking on a single-line passing loop — the domain where
  illegal states were first made unrepresentable, in iron. One
  `isLegal` oracle; five-rung ladder, each rung a named FP technique
  extinguishing a named violation family:

  | rung | technique | states | unsafe | coverage |
  |------|-----------|--------|--------|----------|
  | v0 | primitive soup | 90,000 (slice of ∞) | 1,398 (+88,400 malformed) | 202/202 |
  | v1 | name your atoms | 1,600 | 1,398 | 202/202 |
  | v2 | derive, don't store | 1,600 | 792 | 202/202 |
  | v3 | locking table as a type | 700 | 236 | 202/202 |
  | v4 | parse, don't validate | 464 | **0** | 202/202 |

  Extinction matrix is lower-triangular by design: v1 kills malformed,
  v2 derailment, v3 conflicting greens, v4 collision + green-into-
  occupied. First build compiled clean; numbers matched the hand
  calculation exactly (202 legal states).

## Decisions Made

- **ADR-0001 (measure the gap)**: oracle = spec, fixed world, typed
  ladder; counterexamples canonical by enumeration order.
- **ADR-0002 (enumerate, don't randomize)**: Andrew's position adopted
  — no emulation layer by default. Bounded-exhaustive enumeration
  (SmallCheck's trick) makes the whole report depend only on
  ADTs/records/Maybe, so the cross-runtime identity claim costs zero
  compatibility spend. Portable-PRNG differential fuzzing (Jurist
  ADR-0008) is the separately-priced tier 2.
- **Name & home**: "signal-box" (over interlock, lever-frame), new
  top-level repo — Andrew's picks.
- Passing loop over Y-junction: exactly two compatible route pairs,
  so the locking table is a real ADT, not a degenerate Maybe.

## Session 3: The honesty meter lands (atlas, evening)

### Accomplished

- **Honesty meter built and verified — browser and Julia agree to the
  bit.** Clicking an atlas pixel now also runs the same Atlas.Dynamics
  in the browser (compiled to JS), in lockstep with the frames streamed
  from Julia: same dt, same 4-step stride, same escape/Hill loss check,
  plus a 4×-dt control run. New panel under the orrery: log-scale
  Jacobi-drift strip chart (Julia ink, browser-same-dt green squares
  riding the ink, 4×-dt rust ~2.5 decades above — the (4×)⁴ = 256×
  signature of RK4's order) with the headline "bit-identical across
  N frames (max |Δ| = 0)".
- Verified three ways: Node wire probe on a lost orbit (early-
  termination path mirrors), same probe on a 30-period survivor
  (11,928 RK4 steps, max |Δ| = 0), and a headless-Chrome CDP
  click-through of the real page.
- **The ulp that mattered**: asteroidPeriod spelled a^1.5 as `pow a
  1.5`; Math.pow (JS) and `^` (Julia) are each ~1 ulp with no agreement
  guarantee, and dt is the one number where an ulp forks a chaotic
  trajectory. Both Atlas.Dynamics and the kernel's three mirrored dt
  lines now use `a * sqrt a` — the whole shared integration path is
  exactly-rounded IEEE operations only. (Wire already bit-safe:
  shortest-roundtrip `show` round-trips bits.)
- Diagnosed the morning's "service connection lost — block 13": SDI
  idle-reaped the Julia service; the frontend's WS died mid-sweep and
  reported honestly. Lazy respawn works as designed.

### Decisions Made

- Browser mirrors at the SAME dt (bit-parity headline), not the
  coarse-dt-only variant sketched yesterday; the coarse run stays as
  the control trace showing what real numerical error looks like.
- **No three.js / 3-D orrery** (Andrew floated it after finding the
  rotating-frame view illegible): the CR3BP is planar; 3-D would be
