## Decisions Made

- Zero negation-as-failure in the rule set (a `Fresh` misfire is
  unretractable in a monotone KB); complements as positive snapshot
  axioms. `consistent` (no path Fresh∧Stale) as tested invariant.
- Staleness is a file-target notion: `StaleCascade`/`StaleNewerDep`
  restricted to file-target edges (a phony "stale" is vacuous — caught
  by the smoke test, fixed).
- Missing > Stale in the state overlay (red beats amber for phantom
  targets).
- Link value = leaf-source mass (union, not sum) with Andrew's caveat
  recorded: no value truly conserves through a build system; revisit
  with a grammar-of-graphics pass.
- Sankey height scales with link count so Ecosystem's single edge
  doesn't fill the canvas; edge-less targets render as a shelf.
- Belief premises as a SEPARATE `requires` field, not overloaded into
  `from`: inputs are consumed (extensional, `$^`), requirements are
  believed (intensional, invisible to the recipe). Retraction = pure
  supersession (a `Retract` entry asserts nothing) so revocation stays
  append-only. Blocked needs a demand premise — it means "wants to run
  but may not", never "has a lapsed gate" (the lapse-is-invisible case
  pinned as inability instead).
- Transient vs durable beliefs mirror the intensional/extensional
  split: journal assertions for gates (conformance), `--assume` per
  invocation for standing checks ("link:on") — transient world-facts
  are never persisted as truth.
- **Nix mandated as the substrate's base layer** (AFC, from the
  tree-outputs → thunks → "why not exactly Nix" conversation arc):
  mandated as infrastructure policy at every scale (data-centers in
  view; the two Macs are just the first replication pair), never as a
  dependency of warrant's reasoning layer — three seams only (NAR
  hashes for tree identity, a Nix-expressible predicate over CanMake,
  a pluggable realiser). Dividend: warrant never builds sandboxing/
  hashing/GC/cache. Quartermaster (#238) owns the mandate — its first
  E4-concrete charter item. Plan: `kb/plans/nix-base-layer.md`;
  execution starts tomorrow (MBP flake + install, then qm-nix.sh
  provisions the Mini, replication = identical store paths + closure
  copy without rebuild).
