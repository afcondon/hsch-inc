### cv-router: robust device fallback (commit `f37f71c`)

cv-router was hard-failing on `deepstar up` whenever the CoreAudio device
named `ES-9` wasn't visible — either because the interface was unplugged,
or because macOS only exposed it inside an aggregate (`ES9 then A4C`).
This aborted DeepStar's tier-1 startup at the first service.

Replaced the single-shot device finder with a candidate-list walker that
tries each candidate's `build_output_stream` and falls through on cpal
errors as well as not-found. Three tiers:

1. Exact name match for the requested device
2. Any device whose normalized name contains the requested name
   (catches aggregates like `ES9 then A4C` for `ES-9`)
3. Host default output (degraded mode — OSC port still binds so the
   rest of the rig stack can come up, but CV/Gate doesn't reach modular)

Stale aggregate definitions persist in macOS's CoreAudio listing after
unplug; `build_output_stream` then returns `Invalid property value`. The
new code now logs `failed to open '...' — trying next` and proceeds
instead of aborting. The audio callback also clamps writes to
`min(N_CHANNELS, n_dev_channels)` so a 2-ch fallback device doesn't
panic on out-of-bounds.

Tested manually with both interfaces unplugged → falls through aggregate
attempt to MacBook Pro Speakers, port 57120 binds, deepstar's probe is
satisfied.

### purerl-tidal: combinator parity batch 1 (commit `48434f0`)

Discovered that of the iconic upstream Tidal combinators, only
`fast`, `slow`, `rev`, `cat`, `fastCat`, `slowCat`, `stack`, `overlay`,
`every`, `whenMod`, `iter`, `iter'`, `linger`, `trunc`, `compress`,
`zoom`, `rotL/R`, `segment`, `steptake/drop` exist in
`Tidal.Pattern.Core`. The bottom half of "what makes Tidal feel like
Tidal" — `jux`, `sometimes` family, `degrade` family, `chunk`,
`palindrome`, `stutter`, `striate`, `shuffle`, `superimpose`, `off`,
`fix`/`unfix`, `inside`/`outside`, `range`, `ply`, `brak`, `hurry`,
`loopFirst` — wasn't ported. Even worse, the Calypso cell evaluator
(`Tidal.Eval.Interpret`) only knows `fast`, `slow`, `fastCat`, `stack` —
even `rev` exists in the algebra but isn't reachable from a live cell.

**Decision**: achieve parity with upstream's combinator surface before
inventing new ones. Three batches:

1. **This commit (batch 1)**: trivials + mechanicals — `palindrome`,
   `superimpose`, `off`, `inside`, `outside`, `range`, `brak`,
   `loopFirst`, `stutter`, `ply`, `chunk`. 11 combinators, all ported
   with concrete-valued signatures (purerl-tidal's idiom — no
   patternify wrappers).
2. **Batch 2 (deferred to next session)**: per-event RNG primitive
   unlocks `degrade`/`degradeBy`/`undegradeBy`, `sometimes`/`often`/
   `rarely`/`sometimesBy`, `shuffle`. One small primitive, ~7 free
   combinators.
3. **Design-deferred**: `jux`, `striate`, `fix`/`unfix`, `hurry` — each
   needs design discussion before code (see Decisions below).

Tests: 20 new cases in `runCombinatorTests`, plus a new
`testPatternDirectCount` helper for cases where exact event tuples are
intricate but the count is the property worth pinning. Suite now
253 passing / 0 failing (was 233 / 0). Cell-evaluator wiring not done —
combinators are reachable from PureScript code but not yet from
Calypso cells.

## Decisions Made

- **Combinator parity before invention**: ship full upstream Tidal
  combinator surface in purerl-tidal before extending it. Reasoning:
  Andrew isn't a Tidal user, but err toward upstream-compat keeps the
  named-binding language familiar (memory:
  `feedback_tidal_compat_default`).
- **Cell-evaluator wiring deferred**: the cell parser only exposes
  `fast`/`slow`/`fastCat`/`stack` today. Layer-2 wiring will track the
  algebra in a separate batch — no point wiring half a vocabulary.
- **`jux` semantics: prefer `mult`-as-fan-out**: Andrew's design
  intuition. Modular Y-cable + Aff fork/join readings agree:
  `mult :: Array (Pattern a -> Pattern a) -> Pattern a -> Pattern a`
  is the general primitive; `jux f = mult [id, f]` falls out as sugar.
  Also makes Fugue Machine a 4-way mult. Memory:
  `project_purerl_tidal_jux_design.md`.
- **`hurry` skipped from batch 1**: depends on `speed` ControlPattern
  semantics that are meaningful for samplers but not for pitched
  modular voices (Plaits-pitched, etc.). Defer alongside the
  binding-fork conversation about `jux`.
- **GitHub backup as private**: undecided monorepo vs loose-collection;
  publishing as private repos for now, can be opened later.
