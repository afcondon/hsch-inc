# 2026-07-11 — Modular CV/pitch calibration: probe → tables → in-tune 4-voice Saïch

Turned to the eurorack rig: making the CV we send from the ES-9 produce correct
pitches on the analog VCOs. Built the whole measurement→correction pipeline from
scratch and heard it work. (Earlier in the day: macro-tidal harmonic-authority
work landed on the `macro-tidal` branch — separate effort.)

Full technical writeup: `music/live-coding/deepstar/docs/CALIBRATION.md`.

## Accomplished

- **`deepstar-probe` (Rust)** — new crate in the deepstar repo. cpal captures the
  ES-9 audio input; McLeod/MPM pitch detection (robust to harmonic-rich VCO
  waves). Pure detector unit-tested (sub-2-cent on synthetic sines/saws). Modes:
  `self-test` (no hardware), `list`, `measure` (one-shot JSON), `monitor` (live
  strobe tuner, signed-log needle, for dialing a VCO's base by hand). Committed +
  `docs/CALIBRATION.md` on branch `cv-calibration` (commit `b740cb3`).
- **Six calibration tables swept + stored in Amphora** (`vco-calibrations`):
  Instruo Cruinn (+168c sharp, ~linear), 4MS Ensemble Oscillator (−34c,
  digital plateau), Instruo Saïch ×4 voices on buses 8–11 (+27/+8/+16/+10c —
  each VCO distinct). Median-of-N per point, sub-1c spreads, all locked.
- **The realiser proven — on hardware and by ear.** `verify.py` drove a voice to
  real notes *with correction* and measured: raw's 36c tracking arch collapsed to
  a ~4c band. Then `play.py` drove all four Saïch buses with corrected CV in a
  generative 4-voice texture → **"sounded amazing through the monitors."** The
  "calibrate the output, not the module" thesis is proven.
- **Fixed a real >1-month rig bug**: es9-daemon had been stuck in OSC-only mode
  (no audio device) since it launched when the ES-9 wasn't enumerable — parsing
  `/cv` perfectly but driving nothing. Restarted via Bosun Atlantis
  (`:3994/control/restart?service=es9-daemon`). Captured in memory + the doc.

## Decisions made

- **Correction lives upstream in a per-(module/voice, output) table** — forced by
  hardware (FH-2/ES-9 have no software trim). Keyed by resulting frequency.
- **Store = Amphora** (`kind: "calibration-table"`, label = module/voice slug,
  `vco-calibrations` collection) — not a local file. Guarded three-POST publish.
- **Human/machine split**: the base offset is a one-knob human job (strobe →
  green); the scale/HF curve is the machine's (the table). Per-voice tables
  because the 4 Saïch VCOs need 4 different corrections.
- **Probe DSP in Rust** (cpal + `pitch-detection`), conductor in Go (DeepStar);
  stimulus ES-9 CV via OSC first, FH-2 MIDI later.
- **Operating rule**: always confirm the physical patch with AC before any rig
  test (AC re-patches between steps; invisible here).
