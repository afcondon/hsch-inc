## Lessons (for the library's demo patterns)

- Unkeyed static HATS trees must `clearContainer` before rerender.
- Sugiyama bounds are min/max on BOTH axes (barycenter centring goes
  negative); ghost opacity is canvas-size-dependent (0.45 at full
  window).
- Semantic contraction is cycle-safe iff no directed path between
  members in the rendered subgraph — check that, not depth equality.
- The whole instrument runs on four library calls: solveWith, facts,
  explainFact, and cones derived from explainFact. Good API smell.
