## Decisions Made

1. **Mac Mini as dev server**: all development on Mac Mini, laptop as dumb terminal + browser, phone for approvals via Remote Control
2. **Scope**: 5 DAG projections + dogfooding. Not speed — solid engineering discipline.
3. **Agent phasing**: manual orchestration Weeks 1-4, agent teams Weeks 5-8
4. **Hylograph as supplier**: pause ShapedSteer if Hylograph gaps found, add capability, resume
5. **Minard first**: architectural enforcement ships before ShapedSteer intensive begins
6. **Worktrees default**: containers only for untrusted/experimental agent runs
7. **Handoff via feature branches**: reviewer checks branch, merge is approval
8. **KB authorship**: architect agent writes design docs, human writes decision records
9. **Budget**: stay at Claude Max $100/month; multi-agent + Remote Control should reduce the human bottleneck that made $200 tier underutilized
10. **Remote Control only** (for now): no ntfy.sh setup needed, Claude app auto-discovers sessions
