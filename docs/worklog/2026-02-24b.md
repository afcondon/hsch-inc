# 2026-02-24b — Pedal Explorer: Board Builder + Engine Improvements

## Accomplished

### Board Builder — Dedicated View with Live Audition
- New top-level **Boards** view (Grid | Detail | Boards) replaces the old BoardPanel that lived inside the Detail view
- **PC-only recall**: Board presets send Program Change messages to recall pedal presets, not CC parameter streaming. Only CCs sent are engage/bypass. This matches how the MC6 will program boards.
- **Live audition**: Changing a preset dropdown immediately sends PC; changing engage immediately sends bypass CCs. No separate "apply" step.
- **3-way engage** for single-channel pedals: On / Off / –– (no change)
- **5-way engage** for dual-sided pedals (Onward, MOOD, Flint, Lost+Found): Both / [Channel A] / [Channel B] / Off / ––. Added `engageLabels` to these pedal definitions (e.g. Flint: Trem/Verb, MOOD: ML/Wet)
- **All On / All Off / All ––** toolbar buttons at top of grid — batch-set engage state with live MIDI
- **Overwrite**: Write current builder grid into any saved board preset slot (confirm dialog). Enables quick workflow: recall → tweak → overwrite.
- **Save New**: Captures current grid state as a new board preset with name and notes
- **Load**: Populates grid from a saved preset without sending MIDI, for editing
- Data model: `engaged: boolean` → `engage: "on" | "off" | "a" | "b" | "no-change"` with automatic migration on load. Inline `values` captures stripped.
- `mc6-banks.js` updated for 3-way and 5-way engage (composeMC6Messages, getLibraryOnlyWarnings)
- Wrote `explorer/BOARDS.md` documentation

### Engine & Preset Improvements (pre-existing, committed together)
- `engine.recall()`: Engage CCs now sent before parameter CCs so pedal engines are active when parameters arrive
- `engine.getAllValues()`: Only returns baseline CCs, excludes action/momentary CCs
- `engine.loadAllPedalStates()`: Only restores CCs that exist in baseline (skips stale CCs)
- `presets.recallPreset()`: Always streams CCs (slot assignment is metadata for MC6 programming; slot grid handles PC recall separately)
- **Slot Grid**: New component in preset-panel.js — visual grid of pedal hardware slots, click to send PC. Strymon slots 50-75, Meris slots 0-15. Assigned slots highlighted with pedal color.
- Slot assignment now sends PC to select target slot before physical save
- Baseline cleanups: removed stale CCs from brig, iridium, lex, mercury7; fixed Riverside gain/push value mappings

## Decisions Made
- **PC-only boards**: Board presets recall via PC, never CC streaming. This aligns with how the MC6 will program board recalls (PC messages in MC6 presets). Library-only presets without saved slots simply don't appear in the board builder dropdowns.
- **Dual-sided as "a"/"b" not per-CC**: Rather than exposing raw CC numbers, dual-sided pedals use semantic "a"/"b" values that map to engageCCs[0] and engageCCs[1]. Labels come from `engageLabels` on the pedal definition.
- **All On sends "on" not "a"/"b"**: For dual pedals, All On means both channels. Users pick individual channels via the dropdown.
