## Accomplished

- **Units section** added to `purescript-julia/docs/julia-shaped-libraries.md`
  (commit `3b29375`): dimension-aware PureScript across the seam. The Julia
  fork — **Unitful.jl** (dimensions in type parameters, erase under
  specialization) vs **DynamicQuantities.jl** (dimensions as runtime values,
  no compile blow-up / instability) — is the *same static/dynamic axis* as
  the sizes section, so a PS `Quantity d a` has two landing targets chosen by
  whether units are known at PS compile time. SciML hook: ModelingToolkit
  already checks dimensional consistency on a system's equations, so a
  unit-typed Tier-2 `SystemSpec` validates against the model and labels the
  viz axes from one source of truth.
- **"Is uncertainty a monad?"** subsection (same commit): the precise answer.
  Full distributions *are* a monad (Giry/PPL — the Turing.jl path, where a
  free monad in PS fits); **Measurements.jl is not** — it's first-order
  linear error propagation, a dual-number/forward-AD *ring*. The obstruction
  is sharp: `Functor` needs `f'` not `f`, so you can't push an opaque closure
  through an uncertain value — *the callback anti-pattern restated in
  type-class terms*. Unifying line: units, sizes, and uncertainty are the
  same move — a type-level invariant whose hot propagation stays Julia-side
  because the eDSL exposes structure.
- **Doctrine paragraph reframed** (same commit) to lead with
  **ADTs-as-precision** (illegal states unrepresentable, correct-by-
  construction) and cast the AST/eDSL idioms as a *consequence* of pointing
  that precision at computations — per Andrew's POV.
- **Tier-1 typed handles shipped** as `examples/st-number-vector/`
  (commit `2a88eb0`): `STNumberVector h` is a real Julia `Vector{Float64}`
  (not the generic `Data.Array.ST` shim's `Vector{Any}`), driven by
  `LinearAlgebra`/BLAS — `dot`, `axpy!`, `rmul!`, `norm` — one whole-vector
  FFI call at a time. Region-scoped opaque handle; `ST.run` guarantees no
  escape; `freeze` is the only path back to `Array Number`. Deliberate *no*
  `mapNum` (callback anti-pattern); instead a vocabulary of fused kernels
  (`scale`/`offset`/`expV`/`clampV`). Demo verified end-to-end:
  `dot = 300.0`, `normL2 = 65.72670690061993` (JS-identical number
  formatting), scale/clamp exact.

## Decisions Made

- **Hylograph integration deferred deliberately** (Andrew): the
  visualization seam is well-understood; the interesting work now is
  rounding out the Jurist library surface and professionalising the port.
  The demo goes on last, for demoability.
- **Tier-1 is an `examples/` package, not a built-in shim or a differential-
  suite module** — it carries user FFI (BLAS), and the differential suite is
  foreign-free by design. Same rationale as `lorenz-leaf`.
- **Fused kernels, not `mapNum`** — the library models the doctrine in its
  very API: no closure-per-element path is offered; the general case is
  routed to the (future) Tier-2 `NumExpr` eDSL.

## Accomplished (cont.)

- **`STMatrix` shipped** (commit `1dcc213`): `Matrix{Float64}` handles with
  `mulMV`/`mul`, `det`, `solve` (`\`), `transpose`, `scaleM`, and `lu` /
  `cholesky` factorizations. `cholesky` returns `Maybe` (success = PD
  evidence — the Tier-1 seed of `Checked PosDef`). Verified: `A·x=[6,7]`,
  `det=11`, `A\b=[1/11,7/11]`, exact Cholesky `U`, indefinite matrix →
  `Nothing`, exact LU `U`.
- **Representation-independence rule established** (Andrew's principle, memory
  `no-hardcoded-ps-representation-in-ffi`): user/example FFI shims must not
  hardcode the codegen's runtime encoding of PS ADTs/records. `Maybe`/record
  results are assembled by constructors/builders *handed in* from PureScript
  (`cholesky = choleskyImpl Just Nothing`; `lu = luImpl (\l u p -> {l,u,p})`)
  — the JS backend's `indexImpl(just, nothing)` pattern. No conflict with
  one-go-on-Julia: post-compile those are native Julia closures. "Constructors
  across, handles back." The *core stdlib* shims may still encode the
  representation (co-maintained with the codegen); the rule is for user shims.

  a white-box tripwire asserting raw Julia shapes of compiled PS values
