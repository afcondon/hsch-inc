## Phase 6 (same day): the counting rules — gap closed, theorem earns its keep

- Set out to write `ruleUnrefutedSuggestion`; discovered it is already
  subsumed per-card (EnvelopeByElimination + LastCandidateHand cover the
  envelope-or-suggester residual). The real Z3 gap was **counting**: built
  `DisjunctionCapacity` (f free slots + f disjoint unresolved
  show-disjunctions → hand inside the candidate union — taken as the
  **intersection over all qualifying families**) and
  `DisjunctionPigeonhole` (two showers sharing a 2-card pool exhaust it).
- **War story**: greedy family search was sound and unit-tested but
  flakily broke the player⊇watcher property (~1 in 3 runs). Deterministic
  1600-game hunt: a better-informed mind prunes pools differently, greedy
  picks a different family, the inference vanishes for the mind that knew
  more. Even exact max-family search can't fix it (conclusion depends on
  the choice); the intersection-over-all-families form is provably
  view-monotone. Sound ≠ monotone-in-information; only the property test
  caught it.
- Result: engine at **96–99% of the Z3-optimal watcher**, equal solve
  rate in 6 of 8 configs, zero unsound certainties. Players share the
  engine so games shortened — goldens re-pinned (classic seed-42: 81
  events, A wins turn 33; movement game unchanged). Stats, About tab,
  README, and the formal-methods doc all refreshed.

## Accomplished

- **New project: kibitzer** (`/Users/afc/work/afc-work/kibitzer`, Marginalia
  #251 `kilo-papa-zulu-delta`). A Cluedo simulator whose thesis is that a
  non-playing watcher — zero cards seen — can reconstruct most of a game from
  public metadata (suggestions, passes, "someone showed something"). Built
  plan-first, then four commits: primitives → engine+inference → Halogen
  frontend → Bosun serving.
- **Core** (`kibitzer-core`, pure): ground-truth event log;
  `observe :: Perspective -> Event -> Observation` as the single privacy
  seam; `Knowledge` with per-player holds/lacks sets, envelope in/out,
  live disjunctions, and an append-only fact feed where every fact carries
  provenance (rule + triggering event + originating show-event);
  `saturate` fixpoint over eight named deduction rules; hand-rolled
  Park–Miller LCG (Schrage) so a game is a pure function of its seed.
- **The symmetry that makes it exemplary**: players ARE watchers with richer
  observation streams — same `learn` fold decides when they accuse
  (the engine is dogfooded by the simulation itself).
- **Tests**: golden seed-42 game (96 events; watcher infers 70 facts, sees 0
  cards, places 10 cards exactly) plus property-test theorems at every log
  prefix: soundness, monotonicity, player ⊇ watcher, saturate idempotence.
- **Frontend** (`kibitzer-frontend`, Halogen 7, no hooks): split screen —
  ground truth left, watcher's notebook grid + derivation feed right,
  headline counter "Cards seen: 0 — Facts inferred: N", O(1) scrubbing via
  precomputed `knowledgeTimeline` snapshots, shareable `?seed=` URLs.
  Verified end-to-end with puppeteer-core + headless Chrome (extension was
  not connected).
- **Serving**: registered through Bosun's chair-server (`:3022`) as
  `kilo-papa-zulu-delta:frontend` @ **3026**; fleet.json committed per D-G1
  in the bosun repo (`registry: add frontend kilo-papa-zulu-delta @3026`).

  `:3022/api/ports/suggest` returned 3000, which collides with CodeExplorer
  in Marginalia's legacy rows (the documented seam gotcha). Picked the first

  public residue.

  *before* the reveal).
- 4 players default: uneven hands (5,5,4,4) keep hand-size reasoning
  load-bearing.
