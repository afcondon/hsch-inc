# 2026-05-04 — The Prelude: design tweaks → annotation system → GitHub Pages

Long session. Started with a punch list of small typographic
improvements; ended with the swappable-commentary-tracks system, the
content-format decisions for community contributions, and the site
live on GitHub Pages.

## Accomplished

**Typography pass:**
- Compact treatment for one-line marginalia — detected at parse time
  in Specimen (`Markdown.isCompactMarginalia`), switches the over-
  produced cream-block-with-drop-cap to a flatter in-flow form.
  Single-sentence comments no longer get a marooned drop cap inside
  a wide rectangle.
- Drop-cap kerning tightened (margin-right `0.18em → 0.04em`) — the
  visible P↔roxy gap drops from ~0.7em to ~0.15em.
- Instance bodies restored: previously dropped on parse because
  `InstanceBlock` had no `body` field. Now retained and rendered
  through the same subgrid that aligns value-equation `=` to sig
  `::` columns.
- RHS notes column scaffolded with a new `--rhs-gutter` and a
  `[notes]` track in the `.specimen-stack` grid. All horizontal
  rules (head bottom, row separators, foot top) clipped via abs-
  positioned pseudo-elements to the right edge of the type column so
  they don't project into the editorial space.
- Module-junction cleanup: inter-module rule dropped entirely; foot
  rule lightened (`--ink → --rule`); foot text right-aligned;
  collapsed to a single line `module from <source>`.

**Algorithmic:**
- Prelude-clump fix: filter `import Prelude` as a no-op edge in the
  DAG so convenience-import-only modules layer with the leaves
  rather than parking under the umbrella module. (Project 196 note
  202 had flagged this.)

**Annotation margin (the main event):**
- v1 (briefly): inline italic margin notes per symbol — built,
  shipped, then discarded the moment the swappable-tracks insight
  hit. Was the right transitional step but wrong final form because
  it collapses authorial voice and doesn't scale to long content.
- v2 (final): per-author `commentary/<slug>/<Module>.md` directories
  loaded in parallel with sources. Each row gets one chip per author
  with commentary on its symbol; clicking a chip opens an expansion
  panel in the middle column **saturating in the module's accent
  colour** (var(--accent) → bg, var(--paper) → text). Multi-author
  display is automatic — adding `{ slug: "x", displayName: "X" }` to
  `commentaryTracks` and a directory of files is the entire onboard.

## Decisions made

- **Sidecar markdown over inline annotations** — clean PR diffs, no
  line-drift concerns, symbol-name keyed (`## map`, `## class
  Functor`, etc.).
- **Swappable tracks rather than merged voice** — solves the
  lowest-common-denominator problem of community-edited content.
  Each author's register coexists rather than being washed out.
- **Compact chip in margin, expansion in middle column** — margin
  stays compositional regardless of essay length; opens room for
  long prose and (eventually) Hylograph diagrams.
- **Panel saturates in module's accent colour** — visually distinct
  from cream marginalia and from code; ties editorial register to
  module identity.
- **Article order stays structurally honest** (topo, leaves first);
  pedagogy lives in commentary, not in re-ordering. Sidesteps the
  "Type.Proxy first" pedagogical-hostility tension without
  compromising the structural meaning.
- **Specimen as engine, books as consumers** — the same scaffolding
  will host typeset numerics with Garrood's commentary, Halogen
  with Honeyman et al. Specimen knows nothing about commentary
  semantics, just receives `Map String (Array NoteCard)`.
